Job Application Tracker

Descripton:
This web application helps users track their job applications and their status. Users can use the implemented Job Match feature that lets users compare their skills with job requirements, helping them find matching jobs. The application uses MySQL, Python with Flask, HTML, and CSS.

Features:
- Dashboard displaying statistics of application
- CRUD for all four tables (companies, jobs, applications, contacts): Create, Read, Update, Delete
- Job Match feauture that compares app;icant's skills with job requirements
- Navigation bar throughout site pages

Getting Started
Installing
1. Install Python and MySQL (optional to use Visual Studio Code)
2. Install packages mentioned in the "requirements.txt" document; use pip install -r requirements.txt
3. In MySQL Workbench, run commands in schema.sql
4. Change MySQL login information in database.py
5. Optional if using Visual Studio: Open up project folder in Visual Studio Code 
6. Run python app.py (run python app.py in terminal to start Flask if using visual studio)
7. Open http://127.0.0.1:5000 in your browser
